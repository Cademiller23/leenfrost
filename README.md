# Leenfrost

**Token fiscal gateway for AI agents.**

Leenfrost sits in front of any agent (Snowflake Cortex, OpenRouter, etc.), enforces token budgets, and prunes context by information density *before* the expensive call.

- Measurable 35–50% cost reduction
- Budget enforcement + chargeback ready
- Spend visible in the same warehouse you already use

Built for the Snowflake × Beta Fund Agent & Token Economy Hackathon.
